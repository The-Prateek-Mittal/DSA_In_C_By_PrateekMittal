# DSA_In_C_By_PrateekMittal

📌 About the Repository

This repository contains clean and modular implementations of essential Data Structures and Algorithms (DSA) in the C programming language.
It is ideal for students preparing for interviews, competitive programming, and anyone wanting to strengthen their CS fundamentals.

🧱 Data Structures Implemented

- Arrays

- Linked Lists (Singly, Doubly, Circular)

- Stacks

- Queues (Normal, Circular)

- Trees (Binary Tree, BST)

- Graphs (Adjacency Matrix/List)
